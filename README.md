# Matterix_assets
A collection of 3D models and digital assets designed for robotics and lab automation workflows.
## Promoted reference labware

- `labware/fisherbrand_03-339-21f/` contains the self-modelled Fisherbrand
  03-339-21F vial and its CC0-1.0 provenance.
- `labware/vialplate_3_5/` contains the NIH 3DPX-000429 15-well holder,
  promoted as a separate Public Domain/CC0-1.0 asset, plus the canonical hole
  frame contract used by the Matterix manipulation task.
